# Agent Harness

Универсальный конструктор (обвязка) для любых LLM-агентов.
Позволяет независимо подключать сушку текста, скользящее окно, анализ эмоций, ледник (cold storage) и защиту инструментов (ToolGuard).

## Модули

| Модуль | Что делает |
|---|---|
| `modules/window.py` | Окно контекста: по сообщениям, по ходам или по бюджету токенов + потолок на одно сообщение |
| `modules/tokens.py` | `TokenCounter` — оценка токенов на tiktoken, с фолбэком по символам |
| `modules/sparsifier.py` | Сушка: удаление слов-связок и дробление сложных предложений |
| `modules/analyzer.py` | Эмоция сообщения (rubert-tiny2) |
| `modules/storage.py` | Ледник: журнал всех реплик до обработки + манифест изменений (обратимость) |
| `modules/guard.py` | `ShellCommandGuard` / `SafeToolGuard` — заслон опасным инструментам |
| `adapters/adk.py` | Перевод модулей на колбэки Google ADK |

## Контракт окна

`SlidingWindow` принимает один или несколько ограничителей. Они применяются по цепочке:

1. `max_messages` — оставить последние N сообщений;
2. `max_turns` — оставить последние N ходов (ход = один `invocation_id`);
3. `max_tokens` — выбросить самые старые, пока окно не влезет в бюджет;
4. `max_message_tokens` — сократить **одно** сообщение до головы и хвоста.

Пункты 1–3 решают, **какие** сообщения попадут в запрос; пункт 4 — **сколько** от каждого останется.
Именно пункт 4 даёт рост экономии вместе с размером сообщения: текст короче потолка не меняется
вообще, а длинный режется пропорционально своей длине.

## Обратимость

Любая необратимая обработка (сушка, усечение) пишет в ледник манифест: какие символы оригинала вырезаны
и с каких координат. Восстановление: применить `removed` в обратном порядке — текст совпадает точь-в-точь.

## Тесты

```bash
pip install -e ".[adk,test]"
pytest                 # 20 тестов, сеть и API-ключи не нужны
```

Покрыто: выбор окна по сообщениям/ходам/токенам, потолок на сообщение и рост экономии с размером текста,
полнота ледника, обратимость манифеста, обработка сообщения ровно один раз, сохранение вызовов инструментов,
блокировка опасных инструментов.
