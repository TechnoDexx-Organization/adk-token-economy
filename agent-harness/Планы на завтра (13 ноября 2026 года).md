# Кстати: а можно Агенту сделать память, которую пополнять, чтобы он важные факты о человеке помнил?
Бро, отличный вопрос. И да, это **можно сделать**, причём не ломая то, что уже есть. По сути, ты хочешь не просто «поиск по логам», а **структурированную память фактов** — что-то вроде записной книжки, куда агент сам добавляет важное о человеке.

У нас уже есть `MemoryProvider`, который ищет по `cold_storage.jsonl`. Но это сырые логи. Для фактов нужен отдельный слой. Самый простой и надёжный путь — **JSONL-файл с фактами** и инструмент, который агент может вызывать, чтобы туда писать.

Вот как это выглядит в коде.

### 1. Расширяем `MemoryProvider`

Добавляем в `FileMemoryProvider` (или создаём отдельный класс) методы для работы с фактами. Файл `facts.jsonl` будет лежать рядом с `cold_storage.jsonl`.

```python
# agent-harness/src/harness/modules/memory.py (дополнение)

class FactMemoryProvider:
    """Память фактов о пользователе. Хранит структурированные записи в JSONL."""
    
    def __init__(self, jsonl_path: str):
        self.jsonl_path = Path(jsonl_path)
        self.jsonl_path.parent.mkdir(parents=True, exist_ok=True)

    def add_fact(self, fact: str, source: str = "user") -> None:
        """Добавляет факт в память."""
        entry = {
            "ts": datetime.now(timezone.utc).isoformat(),
            "fact": fact.strip(),
            "source": source,
        }
        with open(self.jsonl_path, "a", encoding="utf-8") as f:
            f.write(json.dumps(entry, ensure_ascii=False) + "\n")

    def search(self, query: str, limit: int = 5) -> list[str]:
        """Ищет факты по ключевым словам (простой скоринг)."""
        if not self.jsonl_path.exists():
            return []
        query_words = set(query.lower().split())
        results = []
        with open(self.jsonl_path, encoding="utf-8") as f:
            for line in f:
                try:
                    entry = json.loads(line)
                    fact = entry.get("fact", "")
                    if not fact:
                        continue
                    fact_words = set(fact.lower().split())
                    if (score := len(query_words & fact_words)) > 0:
                        results.append((score, fact))
                except json.JSONDecodeError:
                    continue
        results.sort(key=lambda x: x[0], reverse=True)
        return [fact for _, fact in results[:limit]]
```

### 2. Даём агенту инструмент для записи фактов

В `agent.py` добавляем функцию `remember_fact`, которую агент сможет вызывать.

```python
# agent.py (дополнение)

    """Запоминает важный факт о пользователе.
```

И добавляем её в список `tools_list`.

### 3. Подключаем факты к контексту

В `adk.py` в методе `_apply_memory_search` можно искать не только в `cold_storage`, но и в фактах, и подмешивать их в контекст.

```python
# adk.py (дополнение в _apply_memory_search)

    memories = self.memory_provider.search(query, limit=3)

        # ... вставка в контекст ...
```

Если хочешь, чтобы факты шли отдельным блоком, можно добавить второй поиск по `fact_memory` и вставлять их как `[Known facts about user]:`.

### 💎 Итог

Ты получаешь **двухуровневую память**:
1. `cold_storage.jsonl` — сырые логи (что говорили).
2. `facts.jsonl` — структурированные факты (что важно помнить).

Агент сам решает, когда вызвать `remember_fact` (например, если ты скажешь «Запомни, что я не люблю утренние созвоны»), и потом эти факты будут подмешиваться в контекст.
