## 📝 Заметки на полях
- *Для интеграции RAG потребуется отдельный проект `memory-service`.*
- *Перед тестированием новых модулей всегда проверять флаги в `.env`.*
- *`memory_rebuild.py` обновлён под новый формат экспорта DeepSeek (`chat_session_index.json` + `chat_sessions/*.json`). Скрипт идемпотентен, пишет атомарно (`.bak` + `os.replace`), формат `memory.md` не меняет.*
- *`accumulated_token_usage` есть в каждом сообщении нового формата DeepSeek — готовый источник для Cost & Token Tracking, без новых парсеров.*
- *Qdrant Agent Skills — это надстройка над знаниями о Qdrant, а не над памятью проекта. RAG и skills не конфликтуют, а дополняют друг друга.*
