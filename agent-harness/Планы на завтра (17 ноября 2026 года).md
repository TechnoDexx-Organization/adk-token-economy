### 6. Продвинутая безопасность (Security Hardening)
*Это следующий уровень защиты. Нужен, когда агент выйдет за пределы локальной машины.*
- [x] **Защита от SSRF (Server-Side Request Forgery):** Запретить `HttpMemoryProvider` обращаться к `127.0.0.1`, `localhost` и приватным подсетям. **СДЕЛАНО (20.11):** новый модуль `modules/ssrf.py` (`is_safe_url`/`find_blocked_urls`): localhost-алиасы, RFC1918/CGNAT/link-local (метаданные облака), не-HTTP схемы, IPv4-in-IPv6, DNS-rebinding, fail closed при ошибке DNS. `HttpMemoryProvider` проверяет URL в конструкторе и перед каждым `search()`, редиректы не переходятся. SSRF-контроль добавлен и в вывод `run_shell_command`.
- [ ] **Песочница для инструментов (Sandboxing):** Изолировать выполнение `run_shell_command` (например, в Podman/Docker или `nsjail`), чтобы даже при обходе Guard агент не мог навредить основной системе.
- [x] **Outbound DLP:** Прогонять через `SecretEditor` не только входящие сообщения, но и исходящие данные (записываемые файлы, внешние HTTP-запросы). **СДЕЛАНО (20.11):** `FileTools.write_file` вырезает секреты до записи на диск (аудит `kind=redaction`, `role=outbound`); исходящие HTTP (`HttpMemoryProvider`) закрыты SSRF-фильтром.
- [ ] **`PromptChunkGuard` (Защита от Prompt Injection):** Реализация сравнения запроса с чанками системного промпта (семантическое/эмоциональное), чтобы блокировать попытки вывести агента из роли. *Частично закрыто канареечными токенами (входящие провокации с маркером блокируются); полноценное семантическое сравнение с чанками промпта — отдельная задача (нужен embedding-бэкенд).*
- [x] **Канареечные токены (Canary Tokens):** Вставить уникальные маркеры в системный промпт. Если они появляются во входящем тексте — сигнал инъекции. **СДЕЛАНО (20.11):** новый модуль `modules/canary.py` (`CanaryGuard`, криптостойкий маркер на сессию). `ADKAgentCallbacks(canary_guard=...)`: маркер в ответе модели => `state["canary_leak"]=True` + аудит; маркер/sha256 во входящем тексте => сообщение заменяется заглушкой `[BLOCKED...]` и не уходит в модель. В ледник пишется только факт хита.
- [ ] **Пре-сканирование входа маленькой моделью:** Использовать `rubert-tiny2` (или отдельный классификатор) как дешевый локальный фильтр *до* основного LLM (поиск паттернов инъекций и обфускации).
- [ ] **Деобфускация на входе (Interleaving/Shuffle):** Если входящий текст похож на шифр с перестановкой — разделить его на каналы и проверить *оба* через `SecretEditor` и `PromptChunkGuard`.
- [ ] **Stego-транспорт (Neural Steganography):** Опциональный модуль для сокрытия передаваемых данных в шуме (с использованием диффузионных моделей). Позволяет передавать данные через враждебные сети (DPI), где трафик выглядит как случайный шум или безобидные картинки.
