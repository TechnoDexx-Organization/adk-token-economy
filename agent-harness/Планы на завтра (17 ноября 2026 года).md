### 🛡️ Закрытые критические уязвимости (Аудит P0)
- [x] **P0-1 (Экономия токенов):** Окно теперь применяется и на шагах с инструментами (контекст не раздувается).
- [x] **P0-2 (Дублирование):** Защита от дублирования текста при многокомпонентных событиях.
- [x] **P0-3 (Обратимость):** Переход на `difflib` opcodes. Точное восстановление текста после `replace` и `cap`.
- [x] **P0-4 (Мультитенантность):** Изоляция кэшей по `session_id` + LRU-вытеснение (защита от утечек между пользователями и Memory Leak).
- [x] **P0-5 (Defense in Depth):** Защита `run_shell_command` внутри `FileTools` (прямой обход Guard заблокирован).
- [x] **P0-6 (Умный Guard):** Внедрен `GuardDecision` Enum, гибридная логика `DENY -> ALLOW -> HITL` (команды больше не блокируются тупо по черному списку).
- [x] **P0-7 (Иммутабельность):** Ответы инструментов копируются, а не мутируют историю сессии.
- [x] **P0-8 (Аудит DLP):** `SecretEditor` логирует вырезанные секреты (по `sha256`) в `ColdStorage`.

- [ ] **Outbound DLP:** Прогонять через `SecretEditor` не только входящие сообщения, но и исходящие данные (записываемые файлы, внешние HTTP-запросы). Чтобы секреты не утекали наружу даже при легитимных действиях агента.
- [ ] **Защита от Prompt Injection:** Реализация `PromptChunkGuard` (эмоциональное/семантическое сравнение запроса с чанками системного промпта), чтобы блокировать попытки вывести агента из роли.
