### 🛠 Что нужно сделать для чистого теста

**Шаг 1: Добавь `reasoning_effort='off'` для Яндекса**
Открой `agent.py`, найди блок `get_llm_model()` и добавь отключение reasoning в ветку `yandex`. Это нужно, чтобы исключить «мысли» из уравнения.

```python
    elif provider == "yandex":
        print("🔌 Используем Yandex AI Studio")
        folder_id = os.getenv("YANDEX_FOLDER_ID")
        return LiteLlm(
            model=f"openai/gpt://{folder_id}/deepseek-v4.1-flash/latest",
            api_base=os.getenv("YANDEX_API_BASE"),
            api_key=os.getenv("YANDEX_API_KEY"),
            extra_headers={"OpenAI-Project": folder_id},
            reasoning_effort='off', # <--- ДОБАВИТЬ СЮДА
        )
```
*(Если Яндекс выдаст ошибку, что не знает такой параметр — просто уберем его. Но обычно OpenAI-совместимые API его проглатывают или поддерживают).*

**Шаг 2: Переключи провайдера**
В файле `.env` поменяй:
```env
AI_PROVIDER=yandex
```

**Шаг 3: Запусти тот же тест**
Прогони те же самые 15 сообщений («Привет, как проходит день?» и т.д.). 
Перед запуском я бы советовал **временно переименовать** текущий `cold_storage.jsonl` (или сохранить его копию), чтобы новый тест писался в чистый файл, и данные не смешались.
