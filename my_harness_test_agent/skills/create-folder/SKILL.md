# Создание папки

Если пользователь просит создать папку, используй скрипт `scripts/create_folder.sh`.

Инструкция:
1. Запусти скрипт через `run_shell_command`: `bash skills/create-folder/scripts/create_folder.sh <имя_папки>`
2. Если скрипт выдал ошибку (например, не передан аргумент), сообщи пользователю.
3. Если успешно — подтверди, что папка создана.
