# Проверка свободного места на диске

## Описание

Проверка свободного места на диске.

## Когда использовать

- Пользователь спрашивает, сколько свободного места осталось на диске.
- Нужно быстро оценить занятость корневого раздела `/`.

## Как выполнить

1. Прочитайте скрипт: `scripts/check_disk.sh`.
2. Выполните команду из скрипта:

   ```bash
   df -h /
   ```

3. Покажите пользователю вывод команды (размер, использовано, доступно, точка монтирования).

## Примечания

- Команда `df -h /` показывает данные только для корневого раздела `/`.
- Если свободного места меньше 10%, предупредите пользователя об этом.
