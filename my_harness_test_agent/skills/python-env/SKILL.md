# Управление Python-окружением

При работе с окружением следуй этим правилам:

1. **Всегда используй `uv` вместо `pip`.** 
   - Установка: `uv pip install <package>`
   - Создание окружения: `uv venv`
2. **Для работы с секретами используй `keyring`.** 
   - Никогда не проси пользователя вводить пароли в открытом виде или использовать `.netrc`.
3. **Если возникает ошибка `ModuleNotFoundError`**, сначала проверь, активировано ли виртуальное окружение (`.venv`).
4. Для быстрой проверки версии Python используй `uv run python --version`.

## Доступные скрипты (Ресурсы)
Если пользователь просит проверить окружение или жалуется на ошибки установки, 
используй инструмент `run_shell_command`, чтобы запустить скрипт по пути:
`bash skills/python-env/scripts/check_uv.sh`
и покажи пользователю его вывод.
