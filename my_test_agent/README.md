# my_test_agent — экспериментальный ADK-агент по экономии токенов

Агент на **Google ADK** + **LiteLLM**, цель которого — снижение расхода токенов
при длинных диалогах без потери качества ответа. Агент формально является
«эхо-агентом» (повторяет текст пользователя), что позволяет чисто измерять
эффект от оптимизаций контекста.

Здесь остаётся только сборка агента и настройки провайдеров. Все механизмы
живут в отдельном пакете [`agent-harness`](../agent-harness).

## Что делает агент

Сборка описана в `agent.py`, механизмы — в `agent-harness`:

1. **Окно контекста** (`SlidingWindow`) — в запрос уходят не все события сессии.
   Три ограничителя работают по цепочке:
   - `max_messages=10` — последние 10 сообщений;
   - `max_tokens=12_000` — жёсткий бюджет окна (старое вылетает по токенам);
   - `max_message_tokens=1_500` — потолок на **одно** сообщение: голова и хвост
     сохраняются, середина заменяется маркером `…[сокращено N токенов]…`.
   Именно потолок делает экономию растущей вместе с размером сообщения.
   Альтернативный режим — `max_turns` (считать ходы по `invocation_id`).
2. **Сушка текста** (`TextSparsifier`) — удаляются слова-связки и «вода»
   (28 выражений: «в общем», «короче», «на самом деле», …), схлопываются
   соседние повторы. Слова со смыслом («однако», «следовательно») не трогаются,
   пока не включён `strict=True`.
3. **Эмоциональный анализ** (`EmotionAnalyzer`) — модель
   `Aniemore/rubert-tiny2-russian-emotion-detection`; метка кладётся в
   `state["current_emotion"]`, а в конец последнего сообщения добавляется
   `[Tone hint: ...]` из `TONE_HINTS`. Считается **один раз на сообщение**.
4. **Статичная инструкция** (`get_static_instruction`) — системный промпт без
   динамики, чтобы провайдер мог кэшировать его.
5. **Ледник** (`ColdStorage`) — `cold_storage.jsonl` получает **все** реплики
   (и пользователя, и модели, и вызовы инструментов) **до** обработки.
   Для каждой необратимой операции пишется **манифест**: какие символы и с каких
   координат вырезаны. Оригинал восстанавливается точь-в-точь.
6. **Спасательный круг** — при пустом ответе или сбое API в ответ подставляется
   последнее сообщение пользователя, счётчик в `state["error_count"]`.
7. **Защита инструментов** — `ShellCommandGuard` блокирует опасные команды
   (`rm -rf`, `mkfs`, fork-бомбы, `curl | bash`).
8. **Переключение провайдеров** (`get_llm_model`) — по переменной `AI_PROVIDER`:
   - `yandex` (по умолчанию) — Yandex AI Studio;
   - `selectel` — Selectel AI Gateway.

## Как это работает при каждом ходе

```
сообщение пользователя
        │
        ▼
before_model — четыре независимых шага
  1. ЛЕДНИК   все новые события (user, model, tool) → cold_storage.jsonl
  2. АНАЛИЗ   только последнее сообщение: эмоция + сушка (+ манифест)
  3. ОКНО     последние N сообщений → бюджет токенов → потолок на сообщение
  4. ТОН      [Tone hint: ...] в конец последнего сообщения окна
        │
        ▼
     LLM (статичная инструкция, кэшируемая)
        │
        ▼
after_model
  • пусто/сбой → подставить последнее сообщение пользователя
  • успех → лог ответа + метрики (prompt/cached tokens), флаг снят
```

## Версия модели

С 15 ноября 2026 Yandex AI Studio отключает **DeepSeek V4.0 Flash** и
**YandexGPT 5 Lite**; актуальная ветка — **DeepSeek V4.1 Flash 1017**.

Агент уже на ней: `deepseek-v4.1-flash` у Selectel и
`deepseek-v4.1-flash/latest` у Яндекса. URI нового инстанса совпадает с нашим —
проверено 6 ноября 2026, пин на сборку не нужен. Пакетный режим и выделенные
инстансы отменены, но этот агент их не использует.

## Тарифы и стоимость

Ставки Yandex AI Studio для `DeepSeek v4.1 Flash`, выведенные из счёта за
6 ноября 2026 (сверено с `cache_probe_*.jsonl`):

| Тип токенов | ₽ за 1M |
|---|---:|
| Входные | **299** |
| Исходящие | **500** |
| Кэшированные (чтение) | **74.8** |

Ориентиры стоимости:

* диалог из 15 сообщений с окном (`max_messages=10` + сушка) ≈ **0.91 ₽**;
* кэш работает блоками по **1024 токена**; хвост префикса сверх блока платится
  как обычный вход, порог срабатывания — 1024 токена совпадающего префикса;
* раздувание префикса ради кэша в этой архитектуре невыгодно: ~1.9–2.3× дороже
  окна (против 5.8× без кэша вовсе).

## Структура проекта

```
my_test_agent/
├── agent.py                # сборка: провайдер, TONE_HINTS, окно
├── measure_tokens_local.py # локальный замер токенов (DeepSeek-токенизатор + tiktoken)
├── cache_probe.py          # замер prompt/cached tokens по провайдерам
├── __init__.py
├── .env                    # ключи провайдеров (не в git)
├── .adk/                   # сессии ADK (session.db)
├── cold_storage.jsonl      # ледник (генерируется)
└── docs/                   # отчёты и логи экспериментов
```

```text
agent-harness/
├── src/harness/
│   ├── modules/            # window, tokens, sparsifier, analyzer, storage, guard
│   └── adapters/adk.py     # перевод модулей на колбэки ADK
└── tests/                  # 25 тестов, без сети и без ключей
```

## Установка

```bash
python -m venv .venv && source .venv/bin/activate

# harness ставится в editable-режиме из соседней папки
pip install -e ../agent-harness[adk]
pip install tiktoken sentencepiece
```

Первый запуск скачает модель эмоций (~25 МБ) из HuggingFace.

## Настройка окружения

Создайте `.env` рядом с `agent.py`:

```dotenv
AI_PROVIDER=yandex

# Yandex AI Studio
YANDEX_API_KEY=...
YANDEX_FOLDER_ID=...
YANDEX_API_BASE=https://llm.api.cloud.yandex.net/v1

# Selectel AI Gateway (если AI_PROVIDER=selectel)
SELECTEL_API_KEY=...
```

## Запуск

```bash
adk web                 # веб-интерфейс ADK Dev UI
adk run my_test_agent   # интерактивный чат в терминале
```

Замеры и проверки:

```bash
python measure_tokens_local.py   # токенизатор: обычный / разреженный / предикаты
python cache_probe.py            # prompt/cached tokens по провайдерам
cd ../agent-harness && pytest    # 25 тестов, сеть не нужна
```

## Замечания

- Обрезка середины (`max_message_tokens`) — это **усечение**, а не сжатие:
  модель не увидит вырезанное, даже если оно важно. Оригинал остаётся в леднике.
- Данные экспериментов (CSV, JSON, отчёты) лежат в `docs/`.
- Эмодзи-вывод и `print`-логирование — для наглядности эксперимента, не для продакшена.
